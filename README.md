# rclone-policy

**Last Updated:** October 2026

This Privacy Policy applies to the personal Google Cloud application created for personal use with **rclone** (the "Application").

---

## 1. Scope & Ownership
This Application is a personal, non-commercial software configuration created solely by and for the repository owner to enable personal file synchronization via [rclone](https://rclone.org/).

## 2. Information Collected & Accessed
The Application requests access to your Google Drive via the official Google Drive API to perform user-initiated file management actions (such as upload, download, move, copy, and delete).

* **User Data:** The Application does not collect, record, log, or store any personal data, profile information, or files on any external server.
* **Credentials & Tokens:** Authentication tokens (OAuth tokens) are stored locally and encrypted exclusively on the user's private machine/device where rclone is executed.

## 3. Data Usage & Sharing
* **Zero Third-Party Sharing:** The Application does not sell, share, transmit, or disclose any user data, tokens, or files to third parties or advertising services.
* **Direct Communication:** All network traffic occurs directly between the user's local device running rclone and the official Google API servers (`https://www.googleapis.com`).

## 4. Google API Limited Use Disclosure
The Application's use and transfer of information received from Google APIs adhere strictly to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## 5. Revoking Access
You can revoke the Application's access to your Google account at any time by visiting your [Google Account Permissions](https://myaccount.google.com/permissions).

## 6. Contact
For any questions regarding this privacy policy or application configuration, please open an issue in this GitHub repository.
